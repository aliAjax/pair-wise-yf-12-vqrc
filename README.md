# 油站网点 · 卸油差量索赔闭环

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、LocalStorage（无新增依赖）
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

一次到站登记油站、油品、单据量和实收量：

1. **罐容校验**：实收量不得超过油罐剩余可用容量（罐容 − 库存 − 冻结占用），否则整单拒绝。
2. **差量阈值**：差量率 =（单据量 − 实收量）/ 单据量，超过千分之五时必须填写铅封编号和差量原因，缺一项整单拒绝，库存、索赔和罐容占用保持原样。
3. **登记即冻结**：登记成功后索赔单为「冻结中」，实收量冻结占用罐容，库存不动。
4. **复查确认**：复查确认后释放冻结、按实收量入库，索赔单变为「已确认入库」。
5. **复查退回**：退回必须填写原因，冻结占用释放，库存保持不变，索赔单变为「已退回」。

筛选、三项指标（待复查索赔笔数 / 已确认入库笔数 / 索赔差量合计 L）、索赔历史和油罐占用均随状态实时更新，全部数据同步到浏览器 localStorage，刷新后保留。

## 文件结构

按模型、校验、界面拆成三个业务文件，无新增依赖：

```
src/business/unloading/
├── model.ts       # 模型：类型、常量、种子数据、localStorage 同步、登记/确认/退回动作与派生指标
├── validation.ts  # 校验：纯函数，罐容、千分之五阈值、铅封/原因/退回原因校验
└── UnloadingPanel.vue  # 界面：登记表单、实时差量提示、索赔历史、复查操作、罐容占用
```
