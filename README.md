# 油站网点 · 卸油差量索赔

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript（无新增依赖）
- 启动：`npm install && npm run dev`，构建：`npm run build`

## 业务闭环

一次到站登记油站、油品、单据量、实收量：

- 实收量不得超过罐容剩余空间（罐容占用 = 实际库存 + 冻结待复查实收量）；
- 差量超过千分之五（5‰）时必须填写铅封编号和差量原因，否则整单拒绝，库存、索赔、罐容占用保持原样；
- 登记成功后索赔先**冻结**：实收量只占罐容、不动库存；
- 复查确认后按**实收量入库**、索赔兑现；
- 退回必须填写原因，库存与罐容占用保持原样（冻结占用释放）。

筛选（区域 / 油品 / 状态）、三项指标（冻结待复查、已兑现索赔、累计实收入库）、
索赔历史与浏览器 localStorage 同步，刷新后保留。

## 文件结构

业务按「模型 / 校验 / 界面」拆为三个文件：

- `src/business/model.ts` —— 站点罐容、卸油单、索赔状态模型；localStorage 持久化；登记/确认/退回领域动作
- `src/business/validation.ts` —— 登记校验纯函数（罐容、数量、5‰ 差量与铅封/原因）
- `src/business/UnloadingPanel.vue` —— 登记表单、罐容看板、指标、筛选与索赔历史界面
